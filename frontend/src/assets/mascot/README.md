# Маскот TaskerBot (OC Assets)

В эту папку вы можете загрузить свои собственные арты персонажа (OC) в формате PNG или WebP с прозрачным фоном.

### Рекомендуемые файлы и состояния:
- `idle.png` — Нейтральное/спокойное состояние (отображается в компактном виде в шапке и по умолчанию).
- `happy.png` — Радостная реакция (кратковременно появляется при выполнении задачи / рутины).
- `done.png` — Триумфальное / довольное состояние (отображается на экране «Сегодня», когда все задачи закрыты).
- `sleep.png` — Отдыхающий маскот (отображается, когда на сегодня нет запланированных задач).

> **Примечание:** Если какого-то файла нет, компонент `<Mascot />` автоматически отобразит стильный графитовый минималистичный векторный силуэт (Linear-style Companion).
